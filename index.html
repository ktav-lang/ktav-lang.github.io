Install

Seven languages, one Rust core

  • Rust reference
    $ cargo add ktav
  • JavaScript / TS native + WASM
    $ npm i @ktav-lang/ktav
  • Python
    $ pip install ktav
  • Go
    $ go get github.com/ktav-lang/golang
  • PHP needs ext-ffi
    $ composer require ktav-lang/ktav
  • Java / JVM JDK 17 · JNA
    $ implementation("io.github.ktav-lang:ktav:0.6.0")
  • C# / .NET
    $ dotnet add package Ktav
